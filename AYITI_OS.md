# Ayiti OS (GoV)

- HaitiDocs MCP `https://mcp.haitidocs.org`
- HaitiDocs catalog `https://www.haitidocs.org/data/api/catalog.json`
- AyitiStats `https://ayitistats.org`
- Portals: MEF, DGI, BRH, OMRH, CNMP
